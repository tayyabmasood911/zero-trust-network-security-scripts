# Security Policy

## Supported Versions

Only the security scripts and configurations maintained on `main` are supported.

| Version | Supported          |
|:--------|:------------------:|
| main    | :white_check_mark: |
| < main  | :x:                |

## Reporting a Security Issue or Zero-Trust Bypass

If you identify a firewall rule bypass, cryptographic vulnerability, or SPIFFE identity spoofing vector:

1. **Do not create public GitHub issues**.
2. Contact maintainer **Tayyab Masood** at **tayyabmasood911@gmail.com** with the subject `[ZERO-TRUST VULNERABILITY] Network Security Bypass`.
3. Provide details of the vulnerable script, network topology, and attack vector.

All vulnerabilities will be acknowledged within 24 hours.
